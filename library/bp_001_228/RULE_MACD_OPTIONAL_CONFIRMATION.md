Conditions: Optional only. If MACD is on the entry chart, use ultra-fast settings 5-35-5 or 3-10-16 instead of 12-26-9, and paper-test them first.
Entry: Take a long only after the MACD line has crossed above the signal line; watch the histogram for fading momentum.
Stop: MACD never replaces the written stop or the caps.
Target and exits: not stated.
Time: Any time.
Refuse if: Using MACD in place of the setup trigger or the stop.
