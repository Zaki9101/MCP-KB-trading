Conditions: New or rebuilding trader.
Entry: Master the basic plays with small size first (100 shares) and one proven strategy; write if-then statements for each play. Learn one setup type at a time.
Stop: Not applicable.
Target and exits: Not applicable.
Time: Start live at 100 shares, one stock, one trade a day, 10,000 shares a day maximum, only after 5-6 green simulator weeks.
Refuse if: Beginners on the staircase: no fades, halts, scalps or hunches.
